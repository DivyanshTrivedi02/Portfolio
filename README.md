This portfolio is built with a bespoke monochrome editorial aesthetic, featuring cutting-edge spatial web physics, interactive WebGL card sliders, 3D drum reel components, and fluid scroll-expansion animations.

Engineered to showcase **Agentic AI**, **Multi-Agent Systems**, **RAG Pipelines**, and **AWS Cloud Architecture**.

## ✦ Featured Flagship Projects

1. **[Quorum — Multi-Agent AI Research Assistant](https://github.com/DivyanshTrivedi02/quorum-multi-agent-research)**
   - Multi-agent research application built with **LangGraph**, **Mistral AI**, **Tavily API**, and **Streamlit**.
   - Coordinates four specialized agents: Search, Reader, Writer, and Critic.
   - Automates web research, source extraction, fact-checking, quality scoring, and Markdown report export.

2. **[AI Video Assistant](https://github.com/DivyanshTrivedi02/AI-Video-Assistant)**
   - Full-stack AI application processing YouTube videos and audio files with **Whisper**, **Sarvam AI**, **LangChain**, and **ChromaDB**.
   - Generates transcripts, titles, and structured summaries with multilingual speech-to-text (English, Hindi, Hinglish).
   - Implements a RAG pipeline with ChromaDB and Hugging Face Embeddings for contextual question answering.
   - Deployed with Docker containerization.

3. **Agentic Knowledge Engine**
   - ChromaDB vector store with Hugging Face embeddings for sub-second semantic search.
   - Contextual retrieval augmented generation with hybrid retrieval.

4. **AWS Cloud Architecture**
   - Cloud deployment and microservices architecture certified by Amazon Web Services (AWS Certified Cloud Practitioner).

5. **Shield Insurance Analytics Dashboard**
   - 4-page interactive Power BI dashboard analyzing 6 months of enterprise insurance data (₹989M Revenue & 27K+ Customers).
   - Time-intelligence DAX measures (DRG, DCG, MoM benchmarks), demographic settlement rates, and sales channel performance.
   - [Live Power BI Dashboard](https://app.powerbi.com/view?r=eyJrIjoiNTU2NjMyZTgtMmUxOS00YmViLWI0YmItNGZiOTg3OTljMGQ0IiwidCI6ImM2ZTU0OWIzLTVmNDUtNDAzMi1hYWU5LWQ0MjQ0ZGM1YjJjNCJ9) &bull; [GitHub Repository](https://github.com/DivyanshTrivedi02/Shield_Insurance_Analytics)
